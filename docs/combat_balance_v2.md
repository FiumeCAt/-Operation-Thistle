## 一、核心设计目标与现有体系问题诊断

### 1.1 现状诊断（基于当前代码与 JSON）
1. **单口径单弹种，缺乏肉伤/穿甲取舍**：除 12 Gauge 拥有鹿弹/独头/穿甲独头 3 种弹药外，其余 9 种口径均为单一弹种（如 `9mm` 固定 `18 伤 / 22 穿`、`762nato` 固定 `45 伤 / 120 穿`），导致前期手枪/冲锋枪后期无力、步枪只需堆高穿即可通吃一切。
2. **余穿增伤在无甲目标上倒挂**：当前 `DamageModel.resolve_enemy_damage()` 中，击穿公式为 `amount + (ap - armor) * 0.10`。当目标无甲（`armor = 0`）时，高穿弹（如 `ap = 128`）凭空获得 `+12.8` 余穿加伤，反而比高肉伤空尖弹打无甲目标更痛，破坏「高穿略降肉伤、肉伤弹克制无甲变异体」的跷跷板。
3. **敌人缺乏生态分化**：现有 8 种敌人虽有 `hit_material`（`flesh` / `metal`），但无统一的 `archetype` 生态分类与钝伤/肉伤响应差异，缺少高血低甲的变异体主场来承接霰弹与肉伤弹。
4. **同口径武器失去定位差异**：例如 `M870`（泵动 0.63s 循环）与 `M1014`（0.20s）/ `Saiga-12K`（0.24s + 弹鼓）共用同一份鹿弹伤害；`G17` 与全自动 `G18` 共用 9mm；`FAL`（全自动 0.11s）与 `SR-25`（半自动 0.16s）共用 7.62 NATO，导致慢射速/高精度武器在 DPS 维度被全面压制。

## 二、弹药穿甲分级（T0–T6）与肉伤/穿甲结算模型

> **同档穿甲收敛原则**：同一穿甲 Tier 内，不同口径的穿甲值严格控制在 **±5 ~ ±10 RHA** 误差内（例如 T4 档内 9mm AP `88`、.45 AP `85`、.357 AP `96`；T5 档内 5.7 AP `122`、12G 钨芯独头 `122`、9×39 AP `124`、7.62×39 AP `126`、5.56 AP `128`、7.62 NATO FMJ `126`）。差距体现在**口径肉伤、弹丸数、射程、弹速与后坐**，而不是“同级穿甲天差地别”。

### 2.2 修订后的敌方伤害结算公式（Phase 3B 接入 `DamageModel.gd`）

为解决「穿甲弹打无甲怪反而吃高额余穿增伤」的倒挂问题，并引入三系生态特性，建议调整 `resolve_enemy_damage()` 为：

```text
1) 目标无甲（eff_armor <= 0）：
     dmg = amount * archetype_flesh_mul
     （无甲目标不触发“余穿增伤”，穿甲弹过穿无额外加成；肉伤弹对 mutant 享有 flesh_bonus）

2) 击穿有甲目标（eff_armor > 0 且 eff_ap >= eff_armor）：
     overpen_bonus = min(eff_ap - eff_armor, 30.0) * 0.08    # 最高封顶 +2.4 点
     dmg = (amount + overpen_bonus) * archetype_flesh_mul

3) 未击穿（eff_ap < eff_armor）：
     r = clamp(eff_ap / eff_armor, 0.0, 1.0)
     blunt_mul = lerp(archetype_blunt_floor, 1.0, r * r)
     dmg = max(1.0, amount * blunt_mul)
```

- **余穿增伤封顶（`+2.4` 上限，且仅在击穿实体护甲时生效）**：保留了“高穿打穿薄甲更稳”的正反馈，同时彻底杜绝高穿弹对 `0 RHA` 变异体伤害反超肉伤弹。
- **`flesh_ammo` 标签加成**：标记为 `"role": "flesh"` 的肉伤弹/鹿弹命中 `mutant`（变异系）且击穿/无甲时，触发 `×1.20` 软组织扩张倍率；命中 `mech`（机械系）无此加成。
- **与 Phase 4 弱点系统衔接**：Phase 4 命中弱点部位时，先将部位有效护甲乘以 `weakspot_armor_mul`（机械核心 `0.50` / 人类头部 `0.40` / 变异核心 `0.0`），再对最终伤害乘以 `weapon.weakspot_mul × unit.weakspot_mul`。

### 2.4 轻负担配弹与局内 `Q` 键切弹方案

为避免硬核撤离游戏“逐颗塞弹、配十种散弹库存”的繁琐负担，**完全兼容现有 5 大通用备弹池（`light / medium / heavy / shotgun / special`）与现有 `Q` 键（`ammo_switch`）**：

1. **武备库一次性解锁（永久配方制）**：
   - 每把武器默认已解锁该口径的 **常规弹（`std`）**（霰弹枪默认已解锁 `12g_buck` 鹿弹）；
   - **肉伤弹（`flesh`）**与 **穿甲弹（`ap`）**在武备库「弹药配方」处一次性消耗信用点 + 进阶材料解锁（按口径解锁，同一口径所有武器共享，例如解锁 `9mm_ap` 后 G17 / G18 / TMP 均可使用）。
2. **双弹种预设槽 + 局内 `Q` 键热切（零背包负担）**：
   - 每把携行武器在武备库可设 **主用弹种** 与 **备用弹种**（默认：主用=常规，备用=已解锁的穿甲或肉伤；也可三档循环）；
   - **共享通用备弹池**：切换弹种不单独拆分备弹上限，继续从所属通用池（`light / medium / heavy / shotgun`）扣弹；**代价体现为**：
     - 局内按 **`Q`** 键切弹时，触发一次**战术换弹动作**（时长 = `load_time × 0.85`，管仓枪逐发退出/换压或快速换弹，旧弹匣内未打完子弹自动退回通用备弹池，绝不浪费）；
     - 穿甲弹（T4–T6）在**高阶经济/补给权重**上可选：方案 A（推荐，最轻负担）——仅靠一次性解锁 + 局内 `Q` 键换弹时间 + 「低肉伤高穿甲 vs 高肉伤低穿甲」的纯战术取舍，无额外消耗扣费；方案 B——T5/T6 穿甲弹每发消耗 `1.5` 备弹点数（如重型池 40 点可打 26 发 T6 AP 或 40 发常规弹）。*（评审时请确认倾向方案 A 还是方案 B。）*
3. **HUD 可视化**：
   - 右下角弹药面板在口径文字右侧新增彩色档位徽章（如 `[T0 肉伤]` 橙红 / `[T3 常规]` 琥珀 / `[T5 穿甲]` 冰蓝 / `[T6 特穿]` 金紫），并在下方提示 `[Q] 切弹`。
