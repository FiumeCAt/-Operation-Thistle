# 《蓟花行动 / Operation Thistle》（HellWalker_DollProtocol）

> 基于 **Godot 4.7.2** 开发的俯视 2D 像素战术撤离射击游戏（Top-Down 2D Pixel Tactical Extraction Shooter）。  
> 下潜暗区设施、搜刮材料与进阶组件、迎战三系敌方单位、完成通电或拉闸撤离，或在浪潮生存模式中坚守防线。

---

## 核心特色

### 1. 深度弹道、穿甲与弱点战斗系统
- **18 支差异化枪械与 4 大持枪姿态**：覆盖手枪、冲锋枪、霰弹枪、突击步枪与精确射手/栓动狙击枪（`G17` / `G18` / `M1911` / `FN57` / `Python` / `MP7` / `TMP` / `P90` / `UMP45` / `M870` / `M1014` / `Saiga-12K` / `FAL` / `AKM` / `L85A2` / `SR25` / `VSS` / `AWM`），全武器配备独立射速、后坐力、开镜速度（ADS）、单/连发快慢机（`B` 键）与固有属性加成（5% 步进规整）。
- **RHA 均质装甲与 T0–T6 穿甲体系**：采用 `1 点护甲/穿深 = 0.1 mm RHA` 物理标尺，支持局内 `Q` 键在 3 种弹药（穿甲 / 常规 / 肉伤）间动态切换，设置页可一键切换「穿深值 / RHA mm」显示。
- **可配置部位弱点与伪 3D 弹道**：支持敌人弱点判定（机械单位 `1.5×`、人类/变异体 `2.0×`、弱点有效护甲 `50%`）、专属金红飘字与破甲音效；轻量伪 3D 子弹高度模型兼顾平射手感与近中距空地落地扬尘。
- **战术翻滚与躲闪**：`Space` 触发位移曲线、短暂无敌帧、防穿墙与穿敌防卡角机制，配 HUD 冷却指示器与闪避双天赋。

### 2. 模块化像素人形骨骼与 1:1 换皮系统（Modular Doll Rig v2）
- 锁定 `128px × 1` 单一像素规格与 `160 × 160` 独立 `SubViewport` 像素光栅化，内置二段屈膝步态、弹簧后发/风衣/裙摆次级物理、独立眨眼层、上下半身 360° 瞄准解耦与三阶段团身翻滚。
- 支持 **1:1 换皮契约**（详见 [`docs/character_skin_contract.md`](docs/character_skin_contract.md)）与运行时热切换：
  - **DOLL-01 · 灰蓝猫耳少女（`doll_v2`）**：默认战术人形，支持背挂组件独立显隐接口。
  - **THISTLE-02 · 蓟花战术白裙（`doll_thistle`）**：第二套正式皮肤，零代码继承全套动作与 18 枪姿态。
  - **标准分色体模（`mannequin`）**：动作基准与换皮契约验证包。
- 主菜单新增 **「角色」整备界面**：支持四向朝向、五大动作实机预览，以及按角色独立保存的头顶极简双条血甲自定义配色。

### 3. 视野、声纹感知与成长养成
- **分层视野与声纹系统**：主视野光锥 + 近身黑暗感知 + 声纹方位环（Lv.5 满级解锁声波涟漪共存，支持设置切换）；角色贴身补光默认关闭以防过曝。
- **Lv.50 非线性成长与可开关被动**：数据驱动经验曲线、`机体适应` / `行动津贴` 可独立开关被动、武器等级解锁与 2D 节点式天赋树。
- **武备库、改枪与图鉴**：武器/护甲模块化改装、爆发 DPS 与弱点加成直观展示、敌人与弹药图鉴、5 槽位手动存档与 `.json` 导出/导入/重置。

### 4. 分层混音台、战术电台与多曲原创 BGM
- **7 轨混音总线架构**：`Master（含 Limiter 压限器）← Music / SFX（Weapons / Impacts / UI / Ambience）`，覆盖 18 枪普通与消音多变体采样、材质分层命中音与并发声道上限保护。
- **战术电台与状态化 BGM**：
  - 内置 **11 首原创曲目**（主菜单 3 首 / 局内探索 4 首 / 局内战斗 4 首，新增 8 首五度圈兼容紧凑 `.ogg`，单曲 < 2 分钟），支持随机轮播（防连播）、顺序播放与固定单曲；
  - 支持外部自定义音乐目录（`user://bgm/`，放入 `.ogg / .mp3 / .wav` 即识别），电台面板内置一键打开目录按钮、可拖动进度条、暂停与上下曲切换；
  - 局内采用 **等功率 Crossfade + 120s 续播记忆 + 战斗/探索迟滞防抖**，避免单发试枪或短暂清敌空档反复打断 BGM。

### 5. 高自定义战术 HUD 与设置系统
- 图形化供弹容器 HUD（图文 / 数值 / 图形三模式，`J` 键随时切换）+ 实验性「真实逐发弹匣」。
- **血甲弹药栏自动隐藏**（自动隐藏 / 固定血甲 / 全部固定）与 **左上角操作提示栏三档显示**（默认开局 8 秒后平滑淡出 / 关闭 / 常驻）。
- 实时小地图预览（方形/圆形、比例、缩放及调试 3.0× 扩展）、四套界面主题 + 自定义主题色、可选全局 FPS 显示、三页分页调试终端。

## 基础操作

| 按键 | 功能 |
| :--- | :--- |
| `W / A / S / D` | 移动（配合 `Shift` 冲刺） |
| `Space` | 战术翻滚 / 躲闪 |
| `鼠标左键` | 开火 |
| `鼠标右键` | 举枪瞄准 / 高倍镜开镜（ADS） |
| `R` | 换弹 |
| `Q` | 切换弹药类型（穿甲 / 常规 / 肉伤） |
| `B` | 切换开火模式（全自动 / 半自动） |
| `X` | 收枪 / 拔枪 |
| `J` | 切换弹药 HUD 显示模式（图文 / 数值 / 图形） |
| `E` | 与容器、电源开关、撤离点交互 |
| `Tab` | 打开局内背包 |
| `M` | 展开全图 |
| `Alt + 滚轮` | 调整镜头整体缩放 |
| `Esc` | 暂停菜单 / 系统设置 / 返回 |

## 环境要求与运行

- **引擎版本**：Godot Engine **4.7.2**（Forward+）
- **开发 / 运行**：使用 Godot 4.7.2 打开本项目根目录下的 `project.godot` 即可运行主场景（`scenes/ui/StartMenu2D.tscn`）。
- **命令行快捷调试参数**：
  - `-- --skin=doll_thistle` / `-- --skin=mannequin`：指定角色皮肤包启动
  - `-- --save-path user://custom_save.json`：指定隔离存档路径

## 自动化回归测试

项目内置 **62 项核心自动化回归测试（2,041 条断言）**，覆盖弹道、穿甲、弱点、敌人 AI、寻路、音频混音与 BGM、骨骼动作、UI 设置与存档容灾：

```powershell
powershell -ExecutionPolicy Bypass -File ".\.agents\skills\godot-verify\scripts\run_core_tests.ps1"
```

- 并行 LPT 调度（默认 `Jobs=8`，`--fixed-fps 60`），全量回归约 **45 秒**完成，严格要求 `Fail=0` 且 `ScriptErrors=0`。
- 若 Godot 编辑器同时在后台运行，可附加 `-SkipImport` 跳过无头重复导入。
